# Алхимический атлас ⚗️

Браузерная казуальная игра: три алхимика соревнуются за три тайных открытия на общей карте. Колбочки сохраняются между партиями.

## Текущий статус

**Ранний игровой прототип (v0.1)** — одна карта, 2 компьютерных соперника, рецепты, инвентарь, 3 тайны с наградами 1/2/3 🧪, локальное сохранение колбочек и коллекции промежуточных веществ. Визуальный стиль временный. Это ещё не готовая игра для Яндекс Игр.

## Запуск на Windows

1. Установить Node.js LTS с https://nodejs.org/
2. Скачать репозиторий или клонировать: `git clone https://github.com/AnnaRad1/alchemy-atlas.git`
3. В папке проекта выполнить `npm install`
4. Выполнить `npm run dev` и открыть адрес, который покажет Vite.
5. Проверить сборку командой `npm run build`.

## Правила прототипа

- В начале партии каждый игрок получает 4 случайных базовых ингредиента.
- В начале каждого следующего хода игрок получает ещё 2.
- За ход доступно до 2 превращений.
- Доступные рецепты выделены; промежуточные ингредиенты расходуются при использовании.
- Первая заявка на тайное открытие забирает награду; другие игроки больше не могут получить эту тайну в текущей партии.
- После открытия всех трёх тайн партия заканчивается.
- Колбочки игрока и коллекция сохраняются в localStorage браузера и не обнуляются между партиями.
